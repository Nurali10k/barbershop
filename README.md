# The Gilded Chair

A responsive luxury barbershop landing page built with React 18, Vite, Tailwind CSS, and Lucide icons. It includes services, barber profiles, a photo gallery, client testimonials, and an appointment request form.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Demo content to replace

The shop name, address area, phone number, barber profiles, testimonials, and Unsplash image URLs are sample content. The appointment form validates input and shows an on-page confirmation; connect it to a booking service to receive real appointments.
